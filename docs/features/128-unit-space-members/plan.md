Ambiente: Node 24, pnpm 11, TypeScript 5.9 strict, Prisma 6, NestJS 11, Vite 8, React 19, Vitest com os projetos `api` e `web`, Playwright.

Quem alcança o espaço de uma unidade (lotação direta ou herança) vê, abaixo dos documentos, a seção "Pessoas nesta unidade" com as pessoas lotadas **diretamente** nela, a própria linha primeiro e marcada com o selo "você". Fora desta fatia: membros do espaço livre (135), documentos por herança (152), paginação da lista de membros.
