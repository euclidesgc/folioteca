# D-009 — A geração do contrato exige o ambiente de execução, e por isso falha no CI

- **Fase:** 2 · **Detectada por:** thread principal, confirmada pelo security-auditor · **Data:** 2026-09-02
- **Tipo:** `normal`
- **Afeta:** `03-plan.md` Fase 2, etapa 2.8; o critério `comando` de RF-07.3; o
  job `contrato` que a Fase 5 constrói

**Os docs dizem:**

Etapa 2.8: `scripts/generate-openapi.ts` monta a aplicação e escreve
`apps/api/openapi.json`. O critério `comando` de RF-07.3 exige que
`pnpm --filter api run openapi:generate && git diff --exit-code apps/api/openapi.json`
saia com código 0. A etapa 5.2 põe esse mesmo comando dentro do job `contrato`
do CI.

**A realidade impõe:**

O script boota o `AppModule`, que carrega o `ConfigModule` com
`validationSchema` — então gerar o contrato exige `NODE_ENV` e `DATABASE_URL`
válidas para produzir um documento que não toca banco nenhum. O `.env` é
gitignored por RF-04.2, logo o runner de CI não tem nenhum. Verificado
escondendo o `.env` e rodando o comando do critério:

```
$ pnpm --filter api run openapi:generate
> ts-node --transpile-only scripts/generate-openapi.ts
 ERR_PNPM_RECURSIVE_RUN_FIRST_FAIL  api@0.0.0 openapi:generate
Exit status 1
```

O critério passa na máquina de quem desenvolve, onde o `.env` existe, e reprova
no único lugar onde ele importa. Pior que reprovar: o auditor aponta que "o
caminho de menor resistência é alguém colar uma connection string no workflow" —
o defeito empurra um segredo para dentro de um arquivo versionado.

**Opções:**

- **(a) O script monta um módulo dedicado que importa só os módulos de rota**,
  sem o `ConfigModule`. O contrato passa a ser função apenas dos decoradores,
  que é o que ele descreve. Nenhuma variável de ambiente é lida.
- **(b) Definir variáveis fictícias no processo do script antes de criar a
  aplicação** — faz o comando passar escondendo o acoplamento, e o dia em que o
  boot ler uma variável de verdade a falha volta disfarçada.
- **(c) Versionar um `.env` de CI** — contraria RF-04.2 e a regra 14, e é
  exatamente o caminho que o auditor descreve como o risco.

**Recomendação:** (a). O documento OpenAPI descreve rotas e schemas; depender do
ambiente de execução para descrevê-los é acoplamento sem contrapartida.
Descartei (b) porque um comando que passa por causa de valores falsos não prova
o que o critério quer provar, e (c) porque põe credencial em arquivo versionado
para satisfazer um gate — o inverso do que o gate existe para defender.

**Status:** APROVADA
