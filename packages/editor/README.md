# `packages/editor` — o editor compartilhado

Base do editor de blocos sobre **Plate**, consumida pelos dois apps: por
`apps/web`, que é onde se escreve de verdade, e por `apps/site`, que mostra o
editor funcionando ao lado do texto de apresentação.

Existe para que a demonstração do hotsite seja o produto, e não uma cópia dele
que envelhece sozinha.

## Sobre a base

Plate é MIT, sem fronteira paga: comentários, discussões, histórico de versões e
colaboração estão todos no pacote gratuito. Os componentes de interface são
copiados para dentro do projeto, no modelo do shadcn/ui, e passam a ser código da
casa — editável, não dependência selada.
